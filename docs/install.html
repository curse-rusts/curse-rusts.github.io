Install and first launch

From an empty machine to a world, with a Microsoft account that owns Minecraft: Java Edition.

1. Download the launcher

Take the file for your platform from the releases page. On Linux, the AppImage runs as it is; the tarball holds the same launcher beside its files.

2. Sign in

The launcher opens on the Microsoft sign-in and does not continue without it. Sign in, then the account must own Minecraft: Java Edition. The sign-in window names the code and the address to enter it; the launcher waits for the account and then shows it on the Play page.

3. Let it prepare the game

The launcher looks for an existing Minecraft installation. When it finds one, it prepares Curse's resources from those files; when it does not, it downloads 26.3 from Mojang for the signed-in account. Nothing is taken from a third-party launcher's private folders without that installation being present.

4. Play

Choose the installed version and press Play. The launcher starts the client with the prepared resources; the first start takes longer while the world's resources are read.

Where the files go

The launcher keeps its data in a folder of its own: settings, accounts, installed versions, prepared resources, mods and caches. The game folder holds the world saves and the options, as in the Java game. The launcher's data folder can be moved from its settings; the game folder follows the version you play.

If the game does not start

  • Check that the Microsoft account owns Java Edition, not only a Microsoft account.
  • Check that the GPU driver provides Vulkan or OpenGL 3.3. On Linux, install the Vulkan loader and your GPU's driver.
  • Open the launcher's log from its data folder; the first error line names the missing piece.
