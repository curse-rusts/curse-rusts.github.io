Telemetry

Curse sends nothing. The client has no telemetry endpoint, so there is nowhere for data to go.

What is sent

Nothing. The build has an empty telemetry address, which turns the whole feature off: no performance summary, no launch count, no "I'm playing" ping. The settings that would control those items are present, because the client is the same one that will use them when a service exists, but with no endpoint they never leave the machine.

What would be sent

If an endpoint is configured, the client sends only what the settings allow: performance summaries, crash reports that the player chose to send, and the heartbeat that counts players. It never sends account names, UUIDs, world names, chat, server addresses or file paths. The full schema lives in the source repository's telemetry document.

A local endpoint

For development, CURSE_TELEMETRY_URL names an endpoint; CURSE_TELEMETRY_URL=off turns sending off even when one is set. Tests and automated runs set off.

Why this page exists

Because a page that says nothing is easier to trust than a page that describes a service that is not there. When Curse has a telemetry service, this page will name it, the data it keeps and the way to delete it.
