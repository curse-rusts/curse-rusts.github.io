Telemetry

What telemetry sends, how long it is kept — and that it is currently disabled.

Telemetry is disabled

The Curse launcher does not send any telemetry right now. Nothing is collected, nothing is stored, and nothing is sent to any server.

When telemetry is enabled in the future, the privacy page will explain what is sent and how long it is kept. Until then, there is no data collection to describe.
