Mods

Two kinds of mod run in Curse: data and assets, or native Rust code. Both are off by default.

Content mods

A content mod is a .hmod file: blocks, items, recipes, loot, tags, models, textures, structures. It carries no code. Put it in the game folder's curse-mods/ directory, or open Options, Mods, Browse Mods. A fresh install has no such folder and plays exactly like vanilla.

Native mods

A native mod is a .cmod bundle: Rust that changes the game's own source before it is compiled. The launcher builds it for the installed version and keeps the result in curse-native-mods/. An older .hnmod bundle still loads and is removed when the launcher replaces it.

The registry

The public mod registry is not deployed. The game and the launcher have no index address, so the Mods page lists nothing and the in-game browser asks nothing. Mods installed by hand work today; the registry becomes available when it has an address, not before.

What a mod may do

Each mod declares its capabilities in its manifest: add blocks, items, mob effects or entity types to your worlds, read and write its own storage, or run native code. Options, Mods lists them with what each may do and a switch. A switch applies at once for assets and data; a mod that adds blocks or changes world generation loads on the next start, and the page says so.
