Download Curse

The launcher installs, prepares and updates the game. It is the only file a player needs; the client and its resources come after sign-in. The sign-in comes first: the launcher does not continue without an account.

Builds are published in curse-rusts/downloads: the launcher for Windows and Linux, and the game and server archives the launcher installs.

Before you start

You need a Microsoft account that owns Minecraft: Java Edition. Curse plays only with an account that owns the game, and it ships no Minecraft code or assets. When an official or third-party installation is already on the machine, the launcher reuses it; otherwise it downloads 26.3 from Mojang for that account.

Verify a download

Every release carries SHA256SUMS and its signature. Compare the file you downloaded with the checksum from the same release:

sha256sum curse-launcher-linux-x86_64.tar.gz

A file whose hash differs from the release's is not the file that was published.

Server

Hosts take the server archive from the same releases page. It contains the supervisor, the engine and the preparer; the archive's README has the first run, the ports and the configuration keys.
