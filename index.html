BEFORE YOU JUMP IN

A few things
to know.

Do I need to own Minecraft?

Yes. You need a Microsoft account that owns Minecraft: Java Edition. The launcher checks ownership and prepares resources from your installation or downloads them from Mojang for your account. Curse does not distribute Minecraft assets.

Is this a mod or a Java launcher?

Curse is a native reimplementation of the client and server in Rust. Its separate launcher is also written in Rust, using GPUI. The game does not run inside a JVM.

Can I use my existing worlds?

Curse reads vanilla saves and supports upgrades from older world versions. Keep a backup before opening an existing world in another game build.

What is available today?

The client, dedicated server and launcher are published for Windows and Linux. Curse's public mod registry, official server, cosmetics and shop are not available. Browse the release notes for the current builds.
