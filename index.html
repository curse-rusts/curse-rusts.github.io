Minecraft: Java Edition 26.3

Java Edition,
without Java.

Curse is a native client and server for Minecraft: Java Edition 26.3. Your worlds, your account, the same rules, in one Rust binary.

Download the launcher Files and requirements

Windows, Linux and macOS. You need a Microsoft account that owns Minecraft: Java Edition.

The game

Survival, creative, redstone, commands.

The client is the game: world generation in all three dimensions, mobs, villagers, raids, redstone, every command, the HUD and the recipe book. Resource packs, data packs and shader packs load as they do in the Java game.

  • Worlds. Vanilla saves open as they are. Worlds from 1.8 to 26.2 are upgraded on the way in.
  • Multiplayer. Join vanilla and Curse servers in online mode, open a world to LAN, or invite friends from the launcher.
  • No Java. The renderer, the server and the tools are native code. There is no JVM to install and no Java process to keep alive.

The server

One program to host.

curse-server supervises the game's engine in server mode: a CLI, a full-screen console, a web panel and a control API, with no Java and no Python on the machine. The world format, the protocol and the rules are the client's own.

  • Ticks. 20 ticks a second on one thread; chunk generation and lighting run on a worker pool.
  • Config. Vanilla's server.properties and eula.txt, plus one server.toml for the supervisor.
  • Operations. Backups, updates and crash restarts are the supervisor's job, not a script's.

The launcher

One file, then the game.

A player downloads the launcher and nothing else. It signs in with Microsoft, finds an existing Minecraft installation or downloads 26.3 from Mojang, prepares the resources the game reads, and keeps the client current. Servers and native mods are built from the same launcher.

The launcher is the only download a player needs. The game, its resources and the server archives are fetched and prepared for the account that signed in.

Parity

Measured against the Java game.

The differential harnesses run vanilla 26.3 and Curse on the same scene, the same seed and the same ticks, then compare what a player can observe: positions, motion, AI state, sounds, packets and rendered output. A harness passes only when every compared value matches.

The project's port ledger reads every vanilla 26.3 method against Curse's code. Player-visible gaps open today: 0 of 833. The audit and what players still run into are in the repository's status section.
